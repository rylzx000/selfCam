## MODIFIED Requirements

### Requirement: 证件汇总展示全部已采集照片

系统 MUST 在模块三预览和最终总预览中展示同一车辆同一证件下所有已采集的电子版、实物正页和实物副页。每类证件 SHALL 在电子证件已上传，或实物正页 + 副页均已上传时视为完成；两种方式满足其一即可，不要求三张全部补齐。系统 MUST 按 `E/F/B` 实际照片矩阵展示补拍入口：无照片时展示整体证件入口；只有电子证件时不展示实物入口；实物链路已开始但正副页尚未齐全时展示缺失实物侧入口，即使电子证件已满足提交完成态；实物正副页齐全或三张齐全时不展示额外入口。展示顺序固定为驾驶证正页、驾驶证副页、驾驶证、行驶证正页、行驶证副页、行驶证；证件采集面板仍 SHALL 保留电子证件和实物证件切换入口。

#### Scenario: 驾驶证三种 side 同时展示
- **WHEN** 同一车辆驾驶证已采集实物正页、实物副页和电子版
- **THEN** 模块三预览和最终总预览都展示 3 张驾驶证照片
- **AND** 展示顺序为驾驶证正页、驾驶证副页、驾驶证

#### Scenario: 行驶证三种 side 同时展示
- **WHEN** 同一车辆行驶证已采集实物正页、实物副页和电子版
- **THEN** 模块三预览和最终总预览都展示 3 张行驶证照片
- **AND** 展示顺序为行驶证正页、行驶证副页、行驶证

#### Scenario: 删除其中一张证件后保留其余照片
- **WHEN** 用户删除同一证件中的一张已采集照片
- **THEN** 该证件其余已采集照片仍继续展示

#### Scenario: 实物证件部分缺失时展示必要补拍入口
- **WHEN** 同一车辆同一证件已采集实物正页但缺少实物副页，或已采集实物副页但缺少实物正页
- **THEN** 模块三预览和最终总预览 MUST 同时展示已采集照片和另一侧实物 `+` 补拍入口
- **AND** 点击缺失正页或副页入口 MUST 直接打开该证件的实物证件面板
- **AND** 入口 MUST 保持当前预览上下文，不得跳转到无 `mode` 的老 document 页或错误预览模式

#### Scenario: 电子加实物单侧过渡态仍可补齐实物证件
- **WHEN** 同一车辆同一证件已采集电子证件，并且仅已采集实物正页或仅已采集实物副页
- **THEN** 该证件类型提交态视为完成
- **AND** 模块三预览和最终总预览 MUST 同时展示电子证件、已采集实物照片和另一侧实物 `+` 补拍入口
- **AND** 点击缺失正页或副页入口 MUST 直接打开该证件的实物证件面板

#### Scenario: 只有电子证件已完成后不展示实物补拍入口
- **WHEN** 同一车辆同一证件只采集了电子证件
- **THEN** 该证件类型视为完成
- **AND** 模块三预览和最终总预览 MUST NOT 展示实物正页或副页 `+` 补拍入口

#### Scenario: 实物证件已完成后不展示电子补拍入口
- **WHEN** 同一车辆同一证件已采集实物正页和实物副页
- **THEN** 该证件类型视为完成
- **AND** 模块三预览和最终总预览 MUST NOT 展示电子证件 `+` 补拍入口

#### Scenario: 打开证件面板不改变完成方式
- **WHEN** 用户点击整体证件入口、缺失侧入口或切换证件面板 tab 后未上传照片
- **THEN** 系统 MUST NOT 更新该证件类型的 `documentSelections`
- **AND** 已完成的电子或实物证件完成状态 MUST 保持不变

#### Scenario: 无已采集证件时展示基础上传入口
- **WHEN** 某车辆驾驶证或行驶证没有任何已采集照片
- **THEN** 预览页仍展示对应的基础上传入口“驾驶证”或“行驶证”
