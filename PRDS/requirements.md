# 需求收集文档

> 状态：✅ 已确认

## 需求概述

微信小程序事故现场照片采集工具，用于按三阶段规范采集现场环境、事故车辆识别信息、车损照片和车辆证件资料，通过辅助框、拍摄指引、预览补拍和缺项提示降低漏拍与错拍，最终将可上传照片逐张提交至后端。

## 核心功能

- **横屏拍照**：横屏三栏布局，相机区、操作区和提示区适配不同手机尺寸
- **模块一：现场环境及车辆信息**：采集 1 张整车 45 度现场照片、最多 2 张现场补充照片，以及每辆车的车牌号和 VIN
- **模块二：车损照片**：按车辆采集车损照片，每车最多 10 张；远景、中景、近景作为拍摄指引，不作为强制分类
- **模块三：证件信息**：按车辆展示驾驶证和行驶证入口，支持电子证件或实物正页、副页
- **多车管理**：辅助拍照模式以后端 `init` 返回车辆为准；无 ticket 的本地流程保留标的车加最多 2 辆三者车
- **分阶段预览**：模块预览只展示本模块内容，最终总预览统一展示全部照片
- **照片管理**：已拍照片支持放大查看、删除和重拍，缺失项可直接进入补拍
- **上传与完成**：车辆级照片已支持逐张 Base64 上传、失败重试和 `complete`；案件级现场照片上传仍待接入
- **照片压缩与缓存**：压缩后保存到本地缓存，支持拍摄中断恢复
- **错误日志排障**：只上报明确的 error 事件，并按 `ticket` 关联后端业务信息

## 暂不实施（后续完善）

- 案件级现场照片上传队列及后端联调
- 登录/鉴权功能

## 使用方式

微信小程序（横屏模式）

## 开发工具

微信开发者工具

## 条件与限制

- 颜色方案：绿灰白，绿色为主色
- 横屏适配：所有UI元素需适配横屏布局
- 去掉小程序自带提示框
- 数据缓存：支持拍摄中断恢复
- 后台对接先只做错误日志落库排障，不上传正常状态、页面行为、warning 或 AI 几何诊断快照
- 错误日志通过启动参数 `ticket` 关联后端业务信息；缺少 `ticket` 或 `ticket` 以 `mock` 开头时不上报后台

## 辅助框设计

| 类型 | 形状 | 说明 |
|------|------|------|
| 车牌号 | 长方形框 | 适配标准车牌比例 |
| VIN码 | 细长横条 | 适配17位字符横向排列 |
| 车损 | 固定大小方框 + 中心十字 | 帮助定位和对齐 |

## 业务流程

```
开始页
  → 模块一：整车 45 度现场照片 → 各车辆车牌/VIN → 模块一预览
  → 阶段完成弹层
  → 模块二：按车辆拍摄车损照片 → 模块二预览
  → 阶段完成弹层
  → 模块三：按车辆补充驾驶证/行驶证
  → 阶段完成弹层
  → 最终总预览
  → 证件缺项提示（不硬拦截）
  → 仅在最终提交前询问是否保存至手机相册
  → 预览页上传遮罩 → 逐张上传并调用 complete
  → 完成页
```
