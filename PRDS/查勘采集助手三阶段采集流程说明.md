# 查勘采集助手三阶段采集流程说明

## 1. 文档目的

本文档用于统一查勘采集助手本轮迭代后的产品流程，重点说明三阶段采集的页面顺序、页面职责、按钮动作和跳转路径。

本文档只描述产品流程，不展开技术实现、接口字段、测试验收或开发排期。

## 2. 流程总览

本轮流程按“先识别现场和车辆，再采集车损，再补齐证件，最后统一预览提交”的顺序组织。

整体流程如下：

1. 开始页
2. 模块一：现场环境及车辆信息
3. 模块一预览页
4. 模块二：车损照片拍摄
5. 模块二预览页
6. 模块三：证件信息页
7. 最终总预览页
8. 提交确认

三个模块的职责边界如下：

| 模块 | 名称 | 采集内容 | 说明 |
|---|---|---|---|
| 模块一 | 现场环境及车辆信息 | 现场照片、补充照片、车辆车牌号、VIN 码 | 环境照片按案件级采集，车牌号和 VIN 按车辆采集 |
| 模块二 | 车损照片拍摄 | 每辆车最多 10 张车损照片 | 只拍车损，不再拍车牌号和 VIN |
| 模块三 | 证件信息页 | 驾驶证、行驶证 | 不做单独线性拍摄流程，通过页面内 `+` 入口补充 |

## 3. 通用原则

### 3.1 分阶段预览

每个模块完成后，先进入本模块预览页或信息页，只展示当前模块相关内容。

最终总预览页再统一展示全部内容。

### 3.2 不硬性拦截缺项

缺少照片或证件时，页面应给出明确提示，但不硬性阻止用户继续后续流程或最终提交。

后续是否需要线下补充，由业务流程继续处理。

### 3.3 补拍和重拍回到当前模块

用户从某个模块的预览页进入补拍、重拍或删除后，应回到当前模块对应页面，不应跳到其他模块或最终总预览页。

### 3.4 本地保存提示

是否保存照片到本地相册，只在最终提交前询问一次。

不在每个模块结束时重复询问。

### 3.5 阶段完成弹层

每个环节跳转到下一环节前，均展示阶段完成弹层，用于提醒用户当前环节已完成，并明确下一步即将进入哪个环节。

阶段完成弹层只负责确认流程切换，不作为最终提交确认。

| 当前页面 | 触发操作 | 弹层确认后 |
|---|---|---|
| 模块一预览页 | 点击进入车损拍摄 | 进入模块二第一辆车车损拍摄页 |
| 模块二预览页 | 点击进入证件信息 | 进入模块三证件信息页 |
| 模块三证件信息页 | 点击进入最终总预览 | 进入最终总预览页 |

弹层内应提供“返回预览”和“确认进入下一环节”两个动作。

阶段完成后可触发后台上传，但最终提交前仍需统一确认。具体上传策略在流程跑通后结合后端对接再细调。

## 4. 开始页

开始页沿用当前系统已有设计，不在本轮强制调整内容。

开始页的主要动作：

| 操作 | 结果 |
|---|---|
| 点击开始采集 | 进入模块一拍摄流程 |

开始采集后，系统根据案件下发信息判断车辆数量。当前主要面向单车事故，多车事故后续可继续完善；如当前案件存在三者车，则模块一、模块二、模块三均按车辆分别展示和采集。

## 5. 模块一：现场环境及车辆信息

### 5.1 模块定位

模块一负责采集事故现场环境照片，以及每辆车的车辆识别信息。

模块一包含两类内容：

1. 案件级现场环境照片
2. 车辆级车牌号和 VIN 码

### 5.2 拍摄顺序

模块一采用线性拍摄流程，推荐顺序如下：

1. 现场照片
2. 标的车车牌号
3. 标的车 VIN 码
4. 三者车车牌号，如有三者车
5. 三者车 VIN 码，如有三者车
6. 模块一预览页

补充照片不进入模块一自然线性流程，不要求用户在进入车牌号和 VIN 前拍满。补充照片只作为模块一预览页里的可选补拍入口。

如果案件只有一辆车，则完成标的车 VIN 码后进入模块一预览页。

如果案件存在三者车，则完成最后一辆车 VIN 码后进入模块一预览页。

### 5.3 现场照片

现场照片为案件级照片，不绑定具体车辆。

现场照片包括：

| 类型 | 数量 | 说明 |
|---|---:|---|
| 现场照片 | 1 张 | 建议拍摄事故现场整车 45 度角 |
| 补充照片 | 最多 2 张 | 用于补充现场环境、事故位置或其他必要信息 |

现场照片至少应提示用户拍 1 张，但不做硬性提交拦截。

补充照片为可选补充项，未拍不计入缺失，不应通过空位或文案诱导用户必须拍满 2 张。

### 5.4 车辆识别信息

每辆车采集两类识别照片：

| 类型 | 数量 | 说明 |
|---|---:|---|
| 车牌号 | 1 张 | 复用当前车牌号拍摄能力 |
| VIN 码 | 1 张 | 复用当前 VIN 码拍摄能力 |

模块一内车牌号和 VIN 码按车辆依次采集。

展示时按车辆分组，例如：

| 车辆分组 | 展示内容 |
|---|---|
| 标的车 - 京A12345 | 车牌号、VIN 码 |
| 三者车 - 京B12345 | 车牌号、VIN 码 |

### 5.5 模块一预览页

模块一预览页只展示模块一内容。

页面分为两块：

1. 现场环境
2. 车辆信息

现场环境展示：

| 内容 | 展示方式 |
|---|---|
| 现场照片 | 已拍则展示照片，未拍则展示 `+` 入口 |
| 补充照片 | 已拍则展示照片，未拍则展示一个 `+` 入口，不需要铺满所有空位 |

车辆信息展示：

| 内容 | 展示方式 |
|---|---|
| 每辆车一个车辆分组 | 一辆车尽量在一行展示车牌号和 VIN 码 |
| 已拍照片 | 直接展示缩略图 |
| 未拍照片 | 展示对应 `+` 入口 |

### 5.6 模块一按钮与跳转

| 页面位置 | 操作 | 结果 |
|---|---|---|
| 拍摄页 | 拍摄完成并确认 | 进入当前线性流程的下一拍摄项 |
| 拍摄页 | 当前为最后一辆车 VIN，拍摄完成并确认 | 进入模块一预览页 |
| 模块一预览页 | 点击照片 | 打开大图预览 |
| 大图预览 | 删除 | 删除当前照片，返回模块一预览页 |
| 大图预览 | 重拍 | 进入对应拍摄页，完成后返回模块一预览页 |
| 模块一预览页 | 点击 `+` | 进入对应补拍页，完成后返回模块一预览页 |
| 模块一预览页 | 点击进入车损拍摄 | 打开阶段完成弹层 |
| 阶段完成弹层 | 点击返回预览 | 返回模块一预览页 |
| 阶段完成弹层 | 点击确认进入车损拍摄 | 直接进入模块二第一辆车的车损拍摄页 |

模块一自然拍摄流程完成最后一个 VIN 后，必须先进入模块一预览页。

只有在模块一预览页确认进入下一环节后，才进入模块二车损拍摄。此时不应重新进入车牌号或 VIN 拍摄流程，也不应跳到最终总预览页。

## 6. 模块二：车损照片拍摄

### 6.1 模块定位

模块二只负责采集车辆损伤照片。

车牌号和 VIN 码已经在模块一完成，模块二不再重复采集。

### 6.2 进入方式

模块二只能从模块一预览页点击“进入车损拍摄”进入。

进入后直接打开第一辆车的车损拍摄页。

### 6.3 拍摄规则

每辆车最多采集 10 张车损照片。

10 张是上限，不是必拍数量。

用户拍摄少于 10 张时，可以继续进入后续流程。

### 6.4 多车流程

如果案件只有一辆车：

1. 进入该车车损拍摄
2. 完成后进入模块二预览页

如果案件存在多辆车：

1. 先拍第一辆车车损
2. 当前车辆完成后，进入下一辆车车损拍摄
3. 所有车辆完成后，进入模块二预览页

### 6.5 模块二预览页

模块二预览页只展示车损照片。

展示规则：

| 内容 | 展示方式 |
|---|---|
| 每辆车一个车辆分组 | 按车辆分别展示 |
| 已拍车损照片 | 直接展示缩略图 |
| 未满 10 张 | 展示一个 `+` 补拍入口即可，不需要用空框补满 10 个位置 |
| 照片较多 | 可横向滑动查看 |

模块二预览页不展示现场环境、车牌号、VIN 码或证件信息。

### 6.6 模块二按钮与跳转

| 页面位置 | 操作 | 结果 |
|---|---|---|
| 车损拍摄页 | 拍摄完成并确认 | 留在当前车辆车损流程，继续拍下一张或结束当前车辆 |
| 车损拍摄页 | 当前车辆完成，仍有下一辆车 | 进入下一辆车车损拍摄页 |
| 车损拍摄页 | 最后一辆车完成 | 进入模块二预览页 |
| 模块二预览页 | 点击照片 | 打开大图预览 |
| 大图预览 | 删除 | 删除当前照片，返回模块二预览页 |
| 大图预览 | 重拍 | 进入对应车辆车损拍摄页，完成后返回模块二预览页 |
| 模块二预览页 | 点击 `+` | 进入对应车辆车损补拍页，完成后返回模块二预览页 |
| 模块二预览页 | 点击进入证件信息 | 打开阶段完成弹层 |
| 阶段完成弹层 | 点击返回预览 | 返回模块二预览页 |
| 阶段完成弹层 | 点击确认进入证件信息 | 进入模块三证件信息页 |

## 7. 模块三：证件信息页

### 7.1 模块定位

模块三负责展示和补充证件信息。

模块三不设计单独的线性证件采集页，直接进入证件信息页。页面内通过 `+` 入口引导用户补拍。

### 7.2 证件范围

本轮不采集身份证。

只采集以下证件：

| 证件 | 说明 |
|---|---|
| 驾驶证 | 出险时驾驶人的驾驶证，支持电子和实物 |
| 行驶证 | 车辆行驶证，支持电子和实物 |

电子证件统一称为“电子驾驶证”“电子行驶证”，不在页面文案中额外强调“12123”。

### 7.3 按车辆分组

驾驶证和行驶证均按车辆分组展示。

如果有两辆车，则分别展示每辆车的驾驶证和行驶证入口及已拍内容。

每辆车尽量一行展示该车全部证件信息，避免同一辆车的证件拆成多行。

### 7.4 证件展示规则

证件信息页直接展示已采集照片，不要求用户点进二级页面后再查看。

展示规则如下：

| 状态 | 展示方式 |
|---|---|
| 未采集 | 展示 `+` 入口 |
| 已采集电子驾驶证 | 展示照片，名称为“驾驶证” |
| 已采集电子行驶证 | 展示照片，名称为“行驶证” |
| 已采集实物驾驶证 | 展示“驾驶证-正页”“驾驶证-副页”等实物页照片 |
| 已采集实物行驶证 | 展示“行驶证-正页”“行驶证-副页”等实物页照片 |

### 7.5 证件补拍入口

用户点击驾驶证或行驶证的 `+` 后，先选择证件形式：

| 选择 | 后续动作 |
|---|---|
| 电子 | 进入电子证件拍摄或上传流程 |
| 实物 | 进入实物证件正页/副页拍摄流程 |

证件拍摄完成后返回模块三证件信息页。

### 7.6 模块三按钮与跳转

| 页面位置 | 操作 | 结果 |
|---|---|---|
| 模块三证件信息页 | 点击驾驶证 `+` | 选择电子或实物，完成后返回模块三证件信息页 |
| 模块三证件信息页 | 点击行驶证 `+` | 选择电子或实物，完成后返回模块三证件信息页 |
| 模块三证件信息页 | 点击已采集照片 | 打开大图预览 |
| 大图预览 | 删除 | 删除当前照片，返回模块三证件信息页 |
| 大图预览 | 重拍 | 进入对应证件拍摄页，完成后返回模块三证件信息页 |
| 模块三证件信息页 | 点击进入最终总预览 | 打开阶段完成弹层 |
| 阶段完成弹层 | 点击返回预览 | 返回模块三证件信息页 |
| 阶段完成弹层 | 点击确认进入最终总预览 | 进入最终总预览页 |

证件缺失时不硬性拦截进入最终总预览页，但应给用户明确提示。

## 8. 最终总预览页

### 8.1 页面定位

最终总预览页用于提交前统一确认全部采集内容。

最终总预览页展示三个模块的全部内容，但不再承载新的线性采集流程。

### 8.2 展示分组

最终总预览页按流程分组展示：

1. 现场环境及车辆信息
2. 车损照片
3. 证件信息

其中：

| 分组 | 展示方式 |
|---|---|
| 现场环境及车辆信息 | 沿用模块一预览页的展示结构 |
| 车损照片 | 沿用模块二预览页的车损展示结构，照片较多时可展开或横向查看 |
| 证件信息 | 沿用模块三证件信息页的展示结构 |

最终总预览页不保留“证件上传”这类额外入口分组，证件入口归入“证件信息”分组。

### 8.3 最终总预览页按钮与跳转

| 页面位置 | 操作 | 结果 |
|---|---|---|
| 最终总预览页 | 点击模块一相关照片或 `+` | 进入对应补拍或重拍流程，完成后返回最终总预览页 |
| 最终总预览页 | 点击模块二相关照片或 `+` | 进入对应车辆车损补拍或重拍流程，完成后返回最终总预览页 |
| 最终总预览页 | 点击模块三相关照片或 `+` | 进入对应证件补拍或重拍流程，完成后返回最终总预览页 |
| 最终总预览页 | 点击提交 | 进入提交确认流程 |

从最终总预览页发起的补拍或重拍，完成后应返回最终总预览页，不应返回模块一、模块二或模块三的阶段页。

## 9. 提交流程

### 9.1 提交前检查

点击提交后，系统检查缺失项。

缺失项按以下口径判断：

| 内容 | 缺失判断 |
|---|---|
| 现场照片 | 案件级现场照片未采集 |
| 补充照片 | 不计入缺失 |
| 车牌号 | 任一车辆车牌号未采集 |
| VIN 码 | 任一车辆 VIN 码未采集 |
| 车损照片 | 任一车辆车损照片为 0 张 |
| 车损照片少于 10 张 | 不计入缺失，10 张为上限不是必拍数量 |
| 驾驶证 | 任一车辆驾驶证未采集 |
| 行驶证 | 任一车辆行驶证未采集 |

缺失项只提示，不硬性阻止提交。

### 9.2 缺失提示

如果存在缺失项，页面应明确告诉用户缺少哪些内容，并提供继续补拍或仍然提交的选择。

| 操作 | 结果 |
|---|---|
| 去补拍 | 回到对应模块或对应补拍页 |
| 仍然提交 | 继续提交流程 |

缺失提示的等级、文案强弱和视觉样式后续单独设计。

### 9.3 本地保存提示

最终提交前，只询问一次是否保存照片到本地相册。

用户选择后进入后续上传和提交。

### 9.4 上传与提交

提交阶段由后端接收案件级照片、车辆级照片、车损照片和证件照片。

上传接口具体改造不在本文档展开。

## 10. 关键跳转规则

以下规则用于避免流程跳错：

| 场景 | 正确结果 |
|---|---|
| 模块一最后一个 VIN 拍完 | 进入模块一预览页 |
| 模块一预览页点击进入车损拍摄 | 打开阶段完成弹层 |
| 模块一阶段完成弹层确认 | 直接进入模块二第一辆车车损拍摄 |
| 模块二开始 | 不再拍车牌号，不再拍 VIN |
| 模块二最后一辆车车损完成 | 进入模块二预览页 |
| 模块二预览页点击进入证件信息 | 打开阶段完成弹层 |
| 模块二阶段完成弹层确认 | 进入模块三证件信息页 |
| 模块三不是线性拍摄 | 直接展示证件信息页，通过 `+` 补充 |
| 模块三点击进入最终总预览 | 打开阶段完成弹层 |
| 模块三阶段完成弹层确认 | 进入最终总预览页 |
| 模块内补拍或重拍 | 回到当前模块对应页面 |
