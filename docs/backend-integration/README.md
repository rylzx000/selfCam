# 后台对接文档

> 状态：设计中，尚未开发
> 最后更新：2026-05-18

本目录用于集中保存 `selfCam` 与在线平台后台对接相关的接口、数据表和联调约定。

当前已确认的后台对接事项：

- [客户端错误日志上报接口](./error-log-api.md)

## 当前边界

- 第一阶段只设计客户端错误日志落库排障能力，不接照片、案件资料或完整业务提交接口。
- 错误日志只上传明确报错事件，不上传页面生命周期、正常拍照流程、AI 几何诊断快照或普通调试日志。
- 小程序启动参数中的报案号字段名为 `reportNo`。
- 当前阶段不新增“缺少 `reportNo` 阻断进入”的前端控制；接口闭环前，缺少 `reportNo` 时只保留本地日志，不调用在线平台错误日志接口。
- 错误日志上传失败不能影响拍照、缓存、预览和完成采集主流程。

## 后续文档约定

- 新增后台接口时，优先在本目录新增独立设计文档。
- 若接口影响产品流程，同步更新 `PRDS/PRD.md`。
- 若接口影响端上模块、配置或数据结构，同步更新 `PRDS/tech.md` 和相关 `docs/` 设计文档。
- 若接口涉及数据库表，设计文档内必须说明表结构、索引、幂等规则和敏感信息边界。
